# Cómo abrir el proyecto en Android Studio

1. Descomprime el .zip.
2. Android Studio → **File → Open** → elige la carpeta `LosPollosHermanos` (la que tiene `settings.gradle.kts`).
3. Espera el *Gradle Sync* (la primera vez descarga cosas; necesita internet).
4. Pon tu `google-services.json` en `app/` (ver `app/ESTE_ARCHIVO_FALTA_google-services.json.txt`) y configura Firebase con `GRADLE_Y_FIREBASE.md` (pasos 3 a 6; los pasos de Gradle ya están hechos).
5. Pon tus imágenes siguiendo `LEEME_IMAGENES.md`.
6. Ejecuta en emulador o celular (▶ Run).
